The `pack generate` command generates a sample pack registry, a new pack, or a variable override file for a pack. See [writing packs](/docs/features/packages/writing-packs).

## Usage

Usage: `norca pack generate <subcommand> [options]`

Run `norca pack generate <subcommand> --help` for help on that subcommand. The following subcommands are available:

- [`pack generate pack`](/docs/commands/pack/generate/pack) - Generate a new pack
- [`pack generate registry`](/docs/commands/pack/generate/registry) - Generate a new registry
- [`pack generate var-file`](/docs/commands/pack/generate/var-file) - Generate a variable override file for a pack
