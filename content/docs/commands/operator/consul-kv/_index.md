The `operator consul-kv` command groups the subcommands for the Consul KV of
the [Consul-compatible API](/docs/configuration/consul_compat) of the clients.

## Usage

Usage: `norca operator consul-kv <subcommand> [options]`

| Subcommand | Description |
| --- | --- |
| [`migrate`](/docs/commands/operator/consul-kv/migrate) | Copy the Consul KV from Variables to the system bus |
