---
title: "Command: pack version"
linkTitle: "pack version"
description: "The pack version command prints the version of norca pack."
---

The `pack version` command prints the version of the built-in pack manager, for example
`Norca Pack v0.4.2-dev` (the Nomad Pack version it is based on).
`norca pack -v` and `norca pack --version` do the same.

## Usage

```plaintext
norca pack version
```

## Examples

```shell
norca pack version
```
