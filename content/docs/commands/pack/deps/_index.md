The `pack deps` command manages the dependencies of a pack. See [pack dependencies](/docs/features/packages/writing-packs#pack-dependencies) and [pack.lock](/docs/features/packages/supply-chain#packlock).

## Usage

Usage: `norca pack deps <subcommand> [options]`

Run `norca pack deps <subcommand> --help` for help on that subcommand. The following subcommands are available:

- [`pack deps vendor`](/docs/commands/pack/deps/vendor) - Vendor the dependencies of a pack
