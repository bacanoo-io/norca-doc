---
title: "Command: pack key generate"
linkTitle: "pack key generate"
description: "The pack key generate command generates a cosign compatible key pair for signing packs."
---

The `pack key generate` command generates an ECDSA P-256 key pair for signing packs, in the format
of `cosign generate-key-pair`: an encrypted private key (`<prefix>.key`) and a public key
(`<prefix>.pub`). Keys generated by cosign can be used as well. The password is read from
`NORCA_PACK_KEY_PASSWORD` (or `COSIGN_PASSWORD`), or asked for interactively. Keep the private key
secret; distribute the public key to the clients that verify packs.

## Usage

```plaintext
norca pack key generate [options]
```

## Key options

- `--force` `(default: false)` - Overwrite existing key files.

- `--output-prefix=<string>` `(default: cosign)` - Prefix of the key files: `<prefix>.key` and `<prefix>.pub`.

## Examples

```shell
export NORCA_PACK_KEY_PASSWORD=...
norca pack key generate --output-prefix=norca-packs
```
