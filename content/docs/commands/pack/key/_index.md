The `pack key` command manages the key pairs used to sign packs. See [signing and trust policies](/docs/features/packages/supply-chain#signing-and-trust-policies).

## Usage

Usage: `norca pack key <subcommand> [options]`

Run `norca pack key <subcommand> --help` for help on that subcommand. The following subcommands are available:

- [`pack key generate`](/docs/commands/pack/key/generate) - Generate a pack signing key pair
