---
title: "Command: pack registry list"
linkTitle: "pack registry list"
description: "The pack registry list command lists the registries of the local environment."
---

The `pack registry list` command lists the cached registries with their refs, the commit of each
ref and their source URL, and the OCI registries of the client configuration.

## Usage

```plaintext
norca pack registry list
```

## Examples

```shell
norca pack registry list
```
